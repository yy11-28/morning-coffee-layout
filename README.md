# ☕ 晨光咖啡 · 布局实战教学站

> 第六章《布局实战：网页排版与视觉细节》课程作业 —— 一个纯原生 HTML/CSS/JS、零依赖的**交互式 CSS 布局教学网站**

以「晨光咖啡」咖啡店落地页为贯穿案例，将 9 个布局知识点串成一条完整工程链路：讲解 → 关键代码 → 可交互演示 → 自学自测 → 错题复盘 → 学习报告导出。

## ✨ 核心亮点

- **单一案例贯穿九节**：导航 → 横幅 → 特色卡 → 菜单九宫格 → 购物车角标 → 页脚，第 9 节拼装成完整页面
- **9 个可交互动态 Demo**：切按钮、拖滑杆、开开关，实时验证布局规则（盒模型 / 文本流 / Position / Flex / Grid / 响应式）
- **第 9 节四阶段装配台**：结构骨架 → 布局排版 → 响应式适配 → 视觉成品，支持一键自动装配
- **100% 中英双语**：全站文案 + 55 条代码注释双语即时切换
- **学习轨迹系统**：阅读 / 实验 / 自测三维度自动检测，进度可视化，一键导出学习报告
- **对错案例总览**：px vs fr、移动端优先 vs 桌面降级、Flex vs Grid、规范 vs 杂乱 UI 四组对比
- **亮暗主题**：CSS 变量统一色彩体系

## 🚀 本地运行

直接双击打开 `index.html` 即可（零依赖）；或本地起一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
